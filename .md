# Social Book

Мини-соцсеть на React + Redux Toolkit.

## Стек
- React 18
- Redux Toolkit (RTK)
- React Redux
- Vite
- CSS Modules

## Запуск

```bash
npm install
npm run dev
```

## Сборка и деплой на GitHub Pages

1. В `package.json` укажи свой `homepage` и логин.
2. В `vite.config.js` укажи `base` = имя репозитория.
3. Собери и задеплой:

```bash
npm run deploy
```

Сайт будет доступен по адресу `https://<логин>.github.io/social-book/`.

## Архитектура

- **app/store.js** — конфигурация Redux store.
- **features/posts/postsSlice.js** — slice со всей логикой постов и комментариев (createSlice + nanoid).
- **features/posts/postsSelectors.js** — мемоизированные селекторы.
- **components/** — презентационные компоненты, чистые, без знания о store.
- Все действия — через `dispatch(action)`.
